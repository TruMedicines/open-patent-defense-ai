Prior-art evidence you can audit line by line.

Find leads, fingerprint your reference files, and build claim charts where every citation needs a page, an exact passage, and a human check. Everything runs in this page. Your files are never uploaded; only the search box contacts Crossref.

Research aid, not legal advice. This page does not decide whether a patent is valid. A search result is a lead, not proof of prior art. Have qualified patent counsel review anything you rely on.

Register files

Each file gets a SHA-256 fingerprint. The file itself stays on your computer; the browser stores only its name, size, fingerprint and the notes below.

Verify files

Browsers can't reopen files on their own. Select the files again and each one is compared against its recorded fingerprint.

Saved leads

Download your evidence ledger and claim chart as one JSON file, or copy it from the box.
