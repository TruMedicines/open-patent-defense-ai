Prior-art evidence you can audit line by line.

Open-source tools that hash your reference files, keep each patent claim limitation separate, and refuse to count a citation until a person has checked it. Everything stays on your machine.

Install and run View the source

A search result is a lead. A citation is evidence.

Most research tools blur the two. This one keeps them in separate places, so a summary written by a model can never be mistaken for a passage somebody actually read in the source.

Find leads

Search Crossref for scholarly publications from the command line. Results are metadata only, and each one needs checking against the original document.

Lock the evidence

Register a file and the ledger records its SHA-256 hash, source URL, publication date, and your notes. Verify later and any changed or missing file is flagged.

Chart each limitation

Generate a claim chart where every limitation has its own evidence list, with exact page or paragraph, a verbatim excerpt, and a human-verified flag.

Quick start

Needs Python 3.10 or newer. The ledger is a plain JSONL file you can read, diff, and commit to your own repository.

  1. Install

    $ git clone https://github.com/YOUR-USERNAME/open-patent-defense-ai
$ cd open-patent-defense-ai
$ python -m pip install -e ".[dev]"

  2. Search for leads

    $ opda search "controlled release drug delivery polymer" --rows 10

  3. Register a document

    $ opda evidence add ./documents/paper.pdf \
    --source-url "https://doi.org/10.xxxx/example" \
    --published 2018-04-12
$ opda evidence verify   # exits 1 if anything changed

  4. Start a claim chart

    $ opda chart init claim-chart.json --patent "US1234567B2"
